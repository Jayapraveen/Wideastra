<h1 align="center">Wideastra</h1>

<h3>A comprehensive downloader for DRM-protected video streams using Widevine and PlayReady.</h3>

> **Disclaimer**  
> Wideastra is intended solely for educational, research, and other lawful uses, such as working with content that you own or are explicitly authorized to access. Unauthorized downloading, redistribution, or circumvention of DRM protections may violate applicable laws and platform terms of service.

## Demonstration

[![Demo Video](https://img.youtube.com/vi/zJX6sWVGS3k/0.jpg)](https://youtu.be/zJX6sWVGS3k)

## Features

- Support for Widevine L1 and L3 workflow, including experimental capabilities
- Experimental PlayReady support based on an adaptation of `pyplayready`
- Stream processing and downloading in MP4 and fragmented formats
- Clean command-line and GUI interface
- Configurable output formats
- Detailed logging and debug mode
- Python script plugins for site-specific extensions
- Experimental video enhancement features, including neural frame regeneration and upscaling; these features require video re-encoding

## Open-Source Timeline

Wideastra will be available in the future with no release date as of now. Wideastra began as an internal project in 2020. The current internal release, v4.6, relies on custom binaries to interface with parts of the Widevine architecture, including device-specific components required for L1 TEE support. As a result, future open-source release will offer fewer features than the internal version.
